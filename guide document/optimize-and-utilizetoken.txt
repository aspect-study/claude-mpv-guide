### Key Insights

- Claude usage limits frustrate users across all subscription tiers ($20, $100, $200), including heavy users on the top plan.
- Usage limits primarily arise due to inefficient prompting, overlong chat histories, and lack of planning before complex tasks.
- Understanding **token consumption** is crucial: simple chat consumes fewer tokens, while building/creating (e.g., coding, dashboards) consumes many.
- **Pre-planning before building** (especially for coding tasks) significantly reduces tokens by avoiding costly rebuilds.
- Long or continuous chats accumulate tokens by requiring Claude to reference vast conversation contexts; multiple, focused chats are more efficient.
- **Project-based memory and instructions** improve efficiency by informing Claude of context consistently and prompting concise, token-saving outputs.
- Creating a **personalized local memory system** with structured markdown files outside Claude ensures control, continuity, and portability of AI memory data.
- **Model stacking**—intentionally using cheaper, less intensive Claude models (like Sonnet, Haiku) for simple tasks and reserving Opus 4.7 (most expensive) for high-stakes tasks—drastically reduces token consumption.
- The Claude ecosystem includes chat, Claude Code, Claude Co-Work, and Claude Design, each with separate token usage tracking and limits.
- API usage for Claude Code separates token consumption from chat, useful for heavy builders or coders.
- Monitoring usage regularly via **claude.ai/settings/usage** helps manage limits and plan usage patterns to avoid unexpected cutoffs.
- Claude’s increasing stinginess with limits is due to energy and compute costs, affecting performance and availability of features on lower plans.
- Rising prices and stricter tiered access mean using **other AI tools/models** (e.g., Grok, Gemini, GPT-based solutions, or self-hosted open-source AI) is often necessary.
- **Claude Skills**—customizable, reusable AI workflows tailored to repetitive tasks—significantly save tokens by reducing re-prompting and error corrections.
- Upgrading subscription plans should be a last resort after optimizing workflows; power users may eventually require $100 or $200 plans due to volume.

### Detailed Framework and Strategies

#### 1. Workflow Optimization: Intentional Prompting

- Avoid using the most powerful model (Opus 4.7) for brainstorming; use cheaper models or plan offline.
- Plan thoroughly before asking Claude to build/code. More planning during conversation burns fewer tokens overall.
- Use **Claude Code’s Plan Mode** to do no-code planning before initiating coding tasks.
- Avoid building and rebuilding without sufficient planning.

#### 2. Managing Chat Length and Context

- Avoid overly long single chats, which increase token usage as Claude reprocesses extensive chat histories.
- Create separate chats organized by project or task to minimize token consumption.
- Load fixed project memories and instructions into chats to reduce the context Claude has to scrape repeatedly.
- Set instructions prompting Claude to keep responses concise and efficient to save tokens.
- Use project folders with memory to maintain consistent, contextual understanding without bloated chats.

#### 3. Building a Local Memory System

- Create a local "AI brain" folder with:
  - `instructions.md`: contains guidelines for Claude about goals and formatting
  - Memory files: regularly updated during interactions to keep memory current and relevant
- Include a directive that memory files must be updated with new session information.
- Use Claude’s **Co-Work** feature to connect chat to local folders, enabling access to owned memory rather than opaque cloud memory.
- Ownership of memory ensures portability between AI systems and long-term usability.
- This system counters the “black box” approach in Claude’s native chat memory.

#### 4. Model Stacking: Using the Right Model for the Right Task

| Model     | Best Use Cases                               | Token and Cost Efficiency              |
|-----------|---------------------------------------------|--------------------------------------|
| Opus 4.7  | Complex tasks: coding, advanced analysis    | Most expensive and token-intensive   |
| Sonnet    | Document analysis, writing, simple editing  | 90% as capable, cheaper and efficient |
| Haiku     | Quick data extraction, web scraping         | Quick, cheap for repetitive tasks    |

- Use Sonnet or Haiku for scraping, routine research, or writing drafts.
- Use Opus 4.7 as a curator to synthesize and analyze outputs from cheaper models.
- In Claude Code, select effort level (low, medium, high, max) according to task complexity to conserve tokens.
- Avoid max effort for simple coding updates.

#### 5. Tool Splitting and Usage Awareness

- Claude includes multiple distinct products:
  - Claude Chat
  - Claude Code
  - Claude Co-Work
  - Claude Design (runs separately with its own limits)
- API access can separate Claude Code token usage from chat usage, beneficial for heavy coding workflows.
- Regularly monitor usage via `claude.ai/settings/usage` to identify which products consume the most tokens.
- Consider pay-as-you-go usage credits for burst needs (e.g., Claude Design), rather than upgrading the whole subscription.
- Awareness of token consumption alters behavior and prevents overuse before important deadlines.

#### 6. Handling Limits and Pricing Reality

- Claude is tightening limits due to energy/compute costs; performance degradation for free/lower-tier plans reported.
- Claude Code is restricted to $100+ plans; $17 plans no longer have access.
- AI subscription costs will likely increase; managing expenditure is critical.
- Consider supplementing Claude with other AI models like Grok (X subscription), Gemini, or open-source local models to balance costs.
- Running local AI models on powerful hardware like a Mac Studio may be an option for heavy users seeking cost control over time.

#### 7. Leveraging Claude Skills for Repetitive Tasks

- Train Claude Skills to automate recurring activities such as:
  - Morning briefing sessions
  - Script writing in your style
  - Portfolio analyses with specific parameters
- Skills anticipate user needs, minimizing corrections and re-prompting, saving tokens.
- Creating skills requires upfront effort but yields significant long-term savings.
- Guides for creating skills are available (referenced in video).

#### 8. Upgrading Subscriptions Strategically

- Avoid jumping to expensive plans without optimizing usage strategies first.
- If usage limits persist post-optimization, higher-tier plans ($100, $200) may be necessary for power users.
- Combining multiple models and tools helps to reduce need for costly upgrades.
- Always track usage and adapt workflows before subscribing to bigger packages.

### Recommended Practices to Avoid Claude Limits

- Plan your prompts carefully before engaging Claude.
- Use cheaper models for brainstorming, web scraping, and routine work.
- Break tasks into multiple, focused chats instead of one long conversation.
- Set up project memories and concise output instructions.
- Maintain your memory locally for control and portability.
- Use Claude Code’s plan mode before coding.
- Monitor usage daily to adjust workflows proactively.
- Use Claude Skills for repetitive workflows.
- Combine Claude with other AI tools to balance costs.
- Only upgrade your subscription after fully optimizing your usage patterns.
