OpenRouter Getting Started Guide

A team orientation manual covering account creation, API key configuration, free model usage, and token expenditure management.

For Internal Team Use Only Prepared by Oliver  ·  June 2026 9 Sections
01

What is OpenRouter?

OpenRouter is a unified API gateway that gives you access to dozens of AI language models from different providers — Meta, NVIDIA, OpenAI, Mistral, Google, and others — through a single endpoint and a single API key.

Instead of maintaining separate accounts and API integrations for each AI provider, you route all your requests through OpenRouter. It handles model routing, load balancing, and billing on your behalf.

1.1 Why We're Using It

The primary motivation is token cost control. Our team's AI usage was previously driven by individual API subscriptions. OpenRouter consolidates this and — critically — provides access to a curated set of high-quality models on a completely free tier, with no credit card required.

Key Benefit

OpenRouter's free tier includes 24+ production-quality LLM models from top providers at zero cost. These are real models — Llama 3.3 70B, NVIDIA Nemotron, Mistral, Kimi, and others — not stripped-down demos.

1.2 How It Works

You create a free OpenRouter account, generate an API key, and use that key in your API calls or in our internal platform. OpenRouter routes your request to the model you specify and returns the response. You never need a separate key per model.

Concept What It Means
API Key Your personal OpenRouter key — starts with sk-or-v1-
Model ID The identifier for a specific AI model, e.g. meta-llama/llama-3.3-70b-instruct:free
Free Tier Models marked :free — no charges, no card required
Rate Limit Max requests per minute per model on the free tier (varies: 5–30 rpm)
Context Window How much text a model can read + write in one request (32K to 200K tokens)
Tokens The unit of text AI processes — roughly 1 token ≈ 0.75 words

Creating Your OpenRouter Account

Account creation takes under 2 minutes. No credit card is required for the free tier.

2.1 Step-by-Step Registration

Open OpenRouter

Open your browser and navigate to https://openrouter.ai

Click Sign Up

Click Sign Up in the top right corner.

Choose registration method

You can register using: Google account (recommended for speed), GitHub account, or Email and password.

Land on the dashboard

After signing in, you will land on the OpenRouter dashboard. No billing setup is needed — the free tier is activated automatically.

Tip — Use Google Sign-In

Google sign-in is the fastest path. No password to remember, and your account is immediately active. If your organization uses Google Workspace, this also ties your account to your work identity.

Once logged in, you will see the main OpenRouter dashboard. The key areas are:

03

Generating Your API Key

Your API key is the credential that authenticates you to OpenRouter. It is used in every API call you or our platform makes on your behalf.

3.1 How to Generate a Key

Navigate to Keys

From the dashboard, click your profile icon or navigate to the Keys section in the left sidebar.

Create Key

Click Create Key.

Give it a name

Give it a descriptive name, e.g. "Team Platform Key — June 2026". Leave the credit limit blank (not applicable for free tier use).

Copy immediately

Click Create and copy the key immediately. It will be shown only once.

Security Notice — Treat Your Key Like a Password

Your API key grants full access to your OpenRouter account. Never share it in chat, email, or commit it to a repository. If you suspect it was exposed, revoke it immediately from the Keys page and generate a new one.

3.2 Key Format

OpenRouter API keys always follow this format:

sk-or-v1-<64-character-token>

If your key does not start with sk-or-v1-, it was not generated correctly. Return to the Keys page and try again.

3.3 Key Rotation Best Practice

Rotate (replace) your key if any of the following occur:

  • You accidentally exposed it — in a message, screenshot, or code commit.
  • A team member who had access to it leaves.
  • You notice unexpected usage spikes in your Usage dashboard.
Rotation Order Matters

To rotate: generate a new key first, update it in the platform, then revoke the old one. Never revoke first — that will cause downtime.

04

Registering on Our Internal Platform

Our team uses an internal AI gateway built on top of OpenRouter. You do not call OpenRouter directly — you register on our platform, enter your OpenRouter key, and the platform handles all API routing for you.

4.1 Platform Registration Flow

Open the platform

Navigate to the platform URL shared by the admin.

Register

Click Register and enter your work email and a password.

Log in

Log in with your credentials. You will be redirected to the Settings page automatically.

Open the API Key tab

On the Settings page, open the API Key tab.

Paste your key and save

Paste your OpenRouter API key (sk-or-v1-...) into the key field and click Save. The platform validates the key live against OpenRouter before storing it.

Playground unlocked

Once validated, the Playground (chat interface) is unlocked for you.

What Happens to Your Key

Your key is encrypted using AES-GCM before being stored. The platform never exposes the raw key value again — not in the UI, not in admin views, not in API responses. Admins can only see whether you have a key configured (yes/no), not the key itself.

4.2 What the Platform Gives You

Once your key is set, you have access to:

AI Playground
A full chat interface with conversation history, model switching, and token usage display.
24+ Free Models
All OpenRouter free-tier models curated and labeled with use cases and limitations.
Conversation History
All your chats are persisted per-conversation in the platform — nothing is lost.
Token Usage Tracking
Real token counts shown after every response — not estimated, pulled from OpenRouter directly.
Daily Usage Limits
Admin-configured per-model daily caps to prevent accidental quota exhaustion.
Model Info Panel
Each model has a description, strengths, limitations, rate limit, and context window.

Using the AI Playground

The Playground is your primary interface for interacting with AI models. It behaves like a polished chat application backed by OpenRouter's free model roster.

5.1 Selecting a Model

The model selector is accessible via the Switch Model button in the top-right of the chat header, or by pressing Ctrl+K (Cmd+K on Mac) from anywhere in the Playground.

The model picker displays:

  • Model name and provider
  • Context window size (e.g. 131K, 200K)
  • Rate limit (requests per minute on the free tier)
  • Best use description and known limitations

Use the keyboard to navigate: arrow keys to move, Enter to select, Esc to close.

5.2 Model Selection Guide

The right model depends on your task. Here is a quick reference based on the free models available on our platform:

Task Type Recommended Model Why
General chat / default use Meta Llama 3.3 70B Instruct Best all-rounder on the free tier
Code generation / debugging Meta Llama 3.3 70B Instruct Strong code output, reliable instruction following
Long document analysis Kimi K2.6 (Moonshot AI) 131K context, built for long-form content
Fast simple tasks Llama 3.2 3B or LFM 2.5 1.2B Low latency, suited for quick completions
Complex reasoning Hermes 3 Llama 405B Largest free model — slow but high quality
Near-GPT-4 quality OpenAI gpt-oss-120b OpenAI training quality, 200K context
Chinese / bilingual tasks GLM-4.5-Air (Z-AI) Optimized for Chinese + English
Experimental / testing OpenRouter Owl Alpha OpenRouter's own model — alpha, not for production

5.3 Conversations and History

Every conversation you start is saved automatically with a title derived from your first message. Your conversation list is in the left sidebar. You can:

  • Click any past conversation to continue it
  • Start a new conversation with the New Chat button
  • Switch models between conversations — each conversation remembers which model it used

5.4 Token Usage Display

After every AI response, the header shows the real token breakdown for that message:

Token Display What It Means
X tokens last response Total tokens for the last exchange (prompt + completion)
X in Tokens sent to the model (your message + conversation history)
X out Tokens in the model's response
Actual Counts, Not Estimates

This is the actual count from OpenRouter — not an estimate. Use it to understand which models are efficient for your use case.

5.5 Daily Usage Limits

The platform enforces admin-configured daily limits per model to prevent quota exhaustion:

  • Default limits: 50 requests / 100,000 tokens per model per day
  • Limits reset at midnight UTC
  • If you hit a limit, you will see an inline error: "Daily limit reached. Resets in Xh Xm"
Switch Models to Continue Working

Limits are per-model, not global. If you hit a limit on one model, switch to a different model to continue working.

Managing Token Expenditure

Although the free tier has no monetary cost, token and request limits still apply. Being intentional about your usage keeps the platform fast and available for the whole team.

6.1 How Tokens Work

Every word you send to an AI model and every word it returns consumes tokens. Your full conversation history is sent on each new message — so long conversations consume more tokens per request than short ones.

Rule of Thumb

1 token ≈ 0.75 words in English. A 500-word message is roughly 670 tokens. A model's response of 300 words is roughly 400 tokens. One exchange in a long conversation could easily consume 2,000–5,000 tokens once history is included.

6.2 Practical Tips to Reduce Token Usage

  • Start a new conversation for new topics. Continuing an old conversation re-sends its entire history. For a fresh topic, start fresh.
  • Be specific in your prompts. Vague prompts lead to long responses. Specific prompts lead to targeted, shorter answers.
  • Use a smaller model for simple tasks. Llama 3.2 3B or LFM 2.5 1.2B are much faster and have the same rate limits for trivial tasks. Save the 70B for tasks that need it.
  • Monitor the token display after each response. If you see unexpectedly high counts, your conversation history may have grown large. Consider starting a new conversation.
  • Use the My Models tab to disable models you never use. Fewer models in the picker means less cognitive overhead when switching. Settings → My Models to toggle.

Managing Your Settings

Your Settings page has three tabs: API Key, My Models, and Account.

7.1 API Key Tab

This is where you add, update, or remove your OpenRouter key. Key states shown:

Status Meaning
Key configured Your key is saved, validated, and active — Playground is unlocked
No key set You have not added a key yet — Playground is locked until you do

To update your key: paste the new key into the field and click Update. The system validates the new key before replacing the old one.

7.2 My Models Tab

You can curate which models appear in your Playground model picker. By default, all admin-enabled models are visible to you. Use the My Models tab to hide models you never use.

Note

If you disable all models in My Models, the Playground will show a warning banner and you will be unable to send messages. Re-enable at least one model to restore functionality.

7.3 Account Tab

Change your platform password here. This does not affect your OpenRouter account — it only changes your login to our internal platform.

Troubleshooting

Problem Solution
"Please add your OpenRouter API key" banner in Playground Go to Settings → API Key tab, paste your sk-or-v1-... key, and click Save.
"Failed to save API key" error on Settings page Your key failed validation. Double-check you copied the full key from OpenRouter. Regenerate if needed.
"Daily limit reached" error mid-conversation You've hit the per-model daily cap. Switch to a different model and continue. Limits reset at midnight UTC.
Model responses are slow (20–40 seconds) Large models like gpt-oss-120b and Hermes 405B are inherently slow on the free tier. Switch to Llama 3.3 70B or a smaller model for faster results.
Playground shows all models disabled warning Go to Settings → My Models and re-enable at least one model.
Token counts seem unexpectedly high Long conversations send full history each request. Start a new conversation to reset context.
OpenRouter API key rejected on openrouter.ai You may have hit your account-level rate limit. Wait a minute and retry, or generate a new key.
Cannot log in to the platform Ensure you are using the correct email and platform password. Contact the admin to reset if needed.
