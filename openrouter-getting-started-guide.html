OpenRouter Getting Started Guide

A team guide covering account creation, API key setup, and how to call OpenRouter models directly via the API using cURL, Python, and JavaScript.

For Internal Team Use Only Prepared by Oliver Lundag  ·  June 2026 4 Sections
01

What is OpenRouter?

OpenRouter is a unified API gateway that gives you access to dozens of AI language models from different providers — Meta, NVIDIA, OpenAI, Mistral, Google, and others — through a single endpoint and a single API key.

Instead of maintaining separate accounts and API integrations for each AI provider, you route all your requests through OpenRouter. It handles model routing, load balancing, and billing on your behalf.

1.1 Why We're Using It

The primary motivation is token cost control. Our team's AI usage was previously driven by individual API subscriptions. OpenRouter consolidates this and — critically — provides access to a curated set of high-quality models on a completely free tier, with no credit card required.

Key Benefit

OpenRouter's free tier includes 24+ production-quality LLM models from top providers at zero cost. These are real models — Llama 3.3 70B, NVIDIA Nemotron, Mistral, Kimi, and others — not stripped-down demos.

1.2 How It Works

You create a free OpenRouter account, generate an API key, and use that key in your API calls or in our internal platform. OpenRouter routes your request to the model you specify and returns the response. You never need a separate key per model.

Concept What It Means
API Key Your personal OpenRouter key — starts with sk-or-v1-
Model ID The identifier for a specific AI model, e.g. meta-llama/llama-3.3-70b-instruct:free
Free Tier Models marked :free — no charges, no card required
Rate Limit Max requests per minute per model on the free tier (varies: 5–30 rpm)
Context Window How much text a model can read + write in one request (32K to 200K tokens)
Tokens The unit of text AI processes — roughly 1 token ≈ 0.75 words
02

Creating Your OpenRouter Account

Account creation takes under 2 minutes. No credit card is required for the free tier.

2.1 Step-by-Step Registration

Open OpenRouter

Open your browser and navigate to https://openrouter.ai

Click Sign Up

Click Sign Up in the top right corner.

Choose registration method

You can register using: Google account (recommended for speed), GitHub account, or Email and password.

Land on the dashboard

After signing in, you will land on the OpenRouter dashboard. No billing setup is needed — the free tier is activated automatically.

Tip — Use Google Sign-In

Google sign-in is the fastest path. No password to remember, and your account is immediately active. If your organization uses Google Workspace, this also ties your account to your work identity.

03

Generating Your API Key

Your API key is the credential that authenticates you to OpenRouter. It is used in every API call you or our platform makes on your behalf.

3.1 How to Generate a Key

Navigate to Keys

From the dashboard, click your profile icon or navigate to the Keys section in the left sidebar.

Create Key

Click Create Key.

Give it a name

Give it a descriptive name, e.g. {{descriptive name}}. Leave the credit limit blank (not applicable for free tier use).

Copy immediately

Click Create and copy the key immediately. It will be shown only once.

Security Notice — Treat Your Key Like a Password

Your API key grants full access to your OpenRouter account. Never share it in chat, email, or commit it to a repository. If you suspect it was exposed, revoke it immediately from the Keys page and generate a new one.

3.2 Key Format

OpenRouter API keys always follow this format:

sk-or-v1-<64-character-token>

If your key does not start with sk-or-v1-, it was not generated correctly. Return to the Keys page and try again.

04

Making API Requests

OpenRouter exposes an OpenAI-compatible REST API. Once you have your API key, you can start making requests immediately — no SDK required. Pick any free model and pass it as the model field.

4.1 Base URL & Authentication

PropertyValue
Base URL https://openrouter.ai/api/v1
Endpoint POST /chat/completions
Auth header Authorization: Bearer <your-key>
Content type Content-Type: application/json
OpenAI-Compatible

OpenRouter's API is a drop-in replacement for the OpenAI API. Any library or tool that supports OpenAI can be pointed at OpenRouter by changing the base URL and API key.

4.2 cURL

The fastest way to test your key. Replace <your-key> with your actual key.

bash 
curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer <your-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "meta-llama/llama-3.3-70b-instruct:free",
    "messages": [
      { "role": "user", "content": "Hello, what can you do?" }
    ]
  }'

4.3 Python (requests)

No SDK required — works with the standard requests library.

python 
import requests

response = requests.post(
    "https://openrouter.ai/api/v1/chat/completions",
    headers={
        "Authorization": "Bearer <your-key>",
        "Content-Type": "application/json",
    },
    json={
        "model": "meta-llama/llama-3.3-70b-instruct:free",
        "messages": [
            {"role": "user", "content": "Hello, what can you do?"}
        ],
    }
)

data = response.json()
print(data["choices"][0]["message"]["content"])

4.6 Next.js (App Router)

Create a server-side API route. Store your key in .env.local — never expose it to the client.

typescript 
// app/api/chat/route.ts
import { NextRequest, NextResponse } from "next/server";

export async function POST(req: NextRequest) {
  const { message } = await req.json();

  const res = await fetch("https://openrouter.ai/api/v1/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.OPENROUTER_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "meta-llama/llama-3.3-70b-instruct:free",
      messages: [{ role: "user", content: message }],
    }),
  });

  const data = await res.json();
  return NextResponse.json({ reply: data.choices[0].message.content });
}

4.7 React.js

Call your own backend route (e.g. the Next.js route above) — never call OpenRouter directly from the browser with your key.

jsx 
import { useState } from "react";

export default function Chat() {
  const [reply, setReply] = useState("");
  const [input, setInput]  = useState("");

  async function send() {
    const res  = await fetch("/api/chat", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ message: input }),
    });
    const data = await res.json();
    setReply(data.reply);
  }

  return (
    <div>
      <input value={input} onChange={e => setInput(e.target.value)} />
      <button onClick={send}>Send</button>
      <p>{reply}</p>
    </div>
  );
}

4.8 Java (Spring Boot)

Uses RestTemplate from spring-boot-starter-web. Store the key in application.properties.

java 
import org.springframework.http.*;
import org.springframework.stereotype.Service;
import org.springframework.web.client.RestTemplate;
import java.util.*;

@Service
public class OpenRouterService {

    private static final String URL =
        "https://openrouter.ai/api/v1/chat/completions";

    @Value("${openrouter.api-key}")
    private String apiKey;

    public String chat(String userMessage) {
        RestTemplate rest = new RestTemplate();

        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_JSON);
        headers.setBearerAuth(apiKey);

        Map<String, Object> body = new HashMap<>();
        body.put("model", "meta-llama/llama-3.3-70b-instruct:free");
        body.put("messages", List.of(
            Map.of("role", "user", "content", userMessage)
        ));

        HttpEntity<Map<String, Object>> request = new HttpEntity<>(body, headers);
        Map response = rest.postForObject(URL, request, Map.class);

        List<Map<String, Object>> choices =
            (List<Map<String, Object>>) response.get("choices");
        Map<String, Object> message =
            (Map<String, Object>) choices.get(0).get("message");
        return (String) message.get("content");
    }
}

4.10 C# (.NET)

Uses HttpClient with System.Text.Json. Target .NET 6 or later.

csharp 
using System.Net.Http;
using System.Net.Http.Headers;
using System.Text;
using System.Text.Json;

var client = new HttpClient();
client.DefaultRequestHeaders.Authorization =
    new AuthenticationHeaderValue("Bearer", "<your-key>");

var payload = new {
    model = "meta-llama/llama-3.3-70b-instruct:free",
    messages = new[] {
        new { role = "user", content = "Hello, what can you do?" }
    }
};

var json    = JsonSerializer.Serialize(payload);
var content = new StringContent(json, Encoding.UTF8, "application/json");

var response = await client.PostAsync(
    "https://openrouter.ai/api/v1/chat/completions", content);

var result = await response.Content.ReadAsStringAsync();
var doc    = JsonDocument.Parse(result);
var reply  = doc.RootElement
    .GetProperty("choices")[0]
    .GetProperty("message")
    .GetProperty("content")
    .GetString();

Console.WriteLine(reply);

4.11 C++

Uses libcurl. Link with -lcurl at compile time.

cpp 
#include <curl/curl.h>
#include <iostream>
#include <string>

static size_t write_cb(void* ptr, size_t size, size_t nmemb, std::string* out) {
    out->append(static_cast<char*>(ptr), size * nmemb);
    return size * nmemb;
}

int main() {
    CURL* curl = curl_easy_init();
    std::string response;

    const std::string body = R"({
        "model": "meta-llama/llama-3.3-70b-instruct:free",
        "messages": [{ "role": "user", "content": "Hello, what can you do?" }]
    })";

    struct curl_slist* headers = nullptr;
    headers = curl_slist_append(headers, "Authorization: Bearer <your-key>");
    headers = curl_slist_append(headers, "Content-Type: application/json");

    curl_easy_setopt(curl, CURLOPT_URL,
        "https://openrouter.ai/api/v1/chat/completions");
    curl_easy_setopt(curl, CURLOPT_HTTPHEADER,    headers);
    curl_easy_setopt(curl, CURLOPT_POSTFIELDS,    body.c_str());
    curl_easy_setopt(curl, CURLOPT_WRITEFUNCTION, write_cb);
    curl_easy_setopt(curl, CURLOPT_WRITEDATA,     &response);

    curl_easy_perform(curl);
    curl_slist_free_all(headers);
    curl_easy_cleanup(curl);

    std::cout << response << std::endl;
    return 0;
}

4.12 Android (Kotlin)

Uses OkHttp. Add com.squareup.okhttp3:okhttp to your build.gradle.

kotlin 
import okhttp3.*
import okhttp3.MediaType.Companion.toMediaType
import okhttp3.RequestBody.Companion.toRequestBody
import org.json.JSONArray
import org.json.JSONObject
import java.io.IOException

val client = OkHttpClient()

val bodyJson = JSONObject().apply {
    put("model", "meta-llama/llama-3.3-70b-instruct:free")
    put("messages", JSONArray().apply {
        put(JSONObject().apply {
            put("role", "user")
            put("content", "Hello, what can you do?")
        })
    })
}

val requestBody = bodyJson.toString()
    .toRequestBody("application/json".toMediaType())

val request = Request.Builder()
    .url("https://openrouter.ai/api/v1/chat/completions")
    .addHeader("Authorization", "Bearer <your-key>")
    .post(requestBody)
    .build()

client.newCall(request).enqueue(object : Callback {
    override fun onFailure(call: Call, e: IOException) = e.printStackTrace()

    override fun onResponse(call: Call, response: Response) {
        val body = response.body?.string() ?: return
        val content = JSONObject(body)
            .getJSONArray("choices")
            .getJSONObject(0)
            .getJSONObject("message")
            .getString("content")
        println(content)
    }
})

4.13 iOS (Swift)

Uses URLSession with async/await. Requires iOS 15+ / Swift 5.5+.

swift 
import Foundation

struct ChatRequest: Encodable {
    let model: String
    let messages: [Message]
    struct Message: Encodable { let role: String; let content: String }
}

var request = URLRequest(
    url: URL(string: "https://openrouter.ai/api/v1/chat/completions")!)
request.httpMethod = "POST"
request.setValue("Bearer <your-key>", forHTTPHeaderField: "Authorization")
request.setValue("application/json",   forHTTPHeaderField: "Content-Type")
request.httpBody = try JSONEncoder().encode(
    ChatRequest(
        model: "meta-llama/llama-3.3-70b-instruct:free",
        messages: [.init(role: "user", content: "Hello, what can you do?")]
    )
)

let (data, _) = try await URLSession.shared.data(for: request)
if let json     = try JSONSerialization.jsonObject(with: data) as? [String: Any],
   let choices  = json["choices"] as? [[String: Any]],
   let message  = choices.first?["message"] as? [String: Any],
   let content  = message["content"] as? String {
    print(content)
}

4.14 OpenAI SDK (Python)

If you already use the openai Python package, just change the base URL and key — no other code changes needed.

python 
from openai import OpenAI

client = OpenAI(
    base_url="https://openrouter.ai/api/v1",
    api_key="<your-key>",
)

completion = client.chat.completions.create(
    model="meta-llama/llama-3.3-70b-instruct:free",
    messages=[
        {"role": "user", "content": "Hello, what can you do?"}

print(completion.choices[0].message.content)
Works with LangChain & LlamaIndex too

Any framework with an OpenAI adapter (LangChain, LlamaIndex, LiteLLM, etc.) can use OpenRouter by setting base_url="https://openrouter.ai/api/v1" and passing your key.

4.15 Response Structure

All responses follow the OpenAI chat completion format.

json 
{
  "id": "gen-1234567890abcdef",
  "model": "meta-llama/llama-3.3-70b-instruct:free",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "Hello! I'm a large language model..."
      },
      "finish_reason": "stop",
      "index": 0
    }
  ],
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 45,
    "total_tokens": 57
  }
}
FieldDescription
choices[0].message.contentThe model's reply text
choices[0].finish_reasonstop = complete, length = hit token limit
usage.prompt_tokensTokens consumed by your input + history
usage.completion_tokensTokens in the model's response
usage.total_tokensTotal billed tokens for this request
